# ReelForge AI - Video Production Kit Generator

ReelForge AI is a full-stack web application that generates complete short-form video production kits (hooks, script, shot-by-shot storyboard, captions, hashtags, and production notes) using Gemini AI.

## Features
- **Studio & Prompt Generator**: Produce comprehensive video assets tailored to platform, duration, audience, tone, and goal.
- **Dual Theme Support**: Modern Dark and Light themes with persistent user preference.
- **History Management**: Automatically stores generated video kits in local storage with search, platform filter, sorting, copy, download, and delete functions.
- **Robust AI Integration**: Resilient JSON parsing and schema normalization to ensure reliable kit generation.

## Tech Stack
- **Frontend**: React 18, Vite, CSS Variables (Dual Theme)
- **Backend**: Node.js, Express, Google Generative AI (Gemini API)
